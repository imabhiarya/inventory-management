First-time setup

This is the first start on this computer. Bring back your data from a backup, or start fresh.

Moving from an old computer?

Choose the backup file you downloaded on the old computer (Backup & Restore → Download Backup). All items, vouchers, ledgers, settings, attachments and user accounts come back, and you sign in with the same username and password as before. No internet is needed.
